# Moving to SMS App

One guide per service: what stays behind, the steps, and the dated facts with a link to check each one. Some of these moves are not worth making, and the guide says so. SMS Mobile App has no HTTP API, so anything your software sends has to stay where it is.

## From an app that uses your phone

- [SMS Gateway for Android (SMSGate)](/compare/sms-gateway-for-android)
- [httpSMS](/compare/httpsms)
- [textbee](/compare/textbee)
- [SMSMobileAPI](/compare/smsmobileapi)
- [Traccar SMS Gateway](/compare/traccar-sms-gateway)
- [SmsGateWay24](/compare/smsgateway24)

## From a hosted SMS provider

- [Twilio](/compare/twilio)
- [Vonage](/compare/vonage)
