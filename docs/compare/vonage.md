# Moving from Vonage to SMS Mobile App

Vonage rents you virtual numbers and prices each message by country. SMS Mobile App uses a SIM you already have and sends only to Pakistani mobile numbers.

## What stays behind

Rented numbers, two-way SMS and anything your software does through the API stay behind. Recipients will see your SIM's number instead.
