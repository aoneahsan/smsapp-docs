# Moving from httpSMS to SMS Mobile App

httpSMS sells an API through your own phone, priced by messages a month. SMS Mobile App is for a person preparing a job in a dashboard.

## What stays behind

Your API calls, the send rate you set per phone and httpSMS's replies stay behind, because SMS Mobile App has no HTTP API and is send-only. Your phone and SIM can stay the same.
