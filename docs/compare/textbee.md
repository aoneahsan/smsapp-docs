# Moving from textbee to SMS Mobile App

textbee is an Android gateway with a dashboard, an API and flat plans. Both send from your SIM, so the move is about how a send gets started.

## What stays behind

API calls, webhooks and n8n or Zapier flows have no equivalent here, and replies are not read. A job you prepare by hand moves across cleanly.
