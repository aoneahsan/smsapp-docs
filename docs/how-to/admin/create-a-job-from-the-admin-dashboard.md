# Create a job in the admin

1. Open the admin batch import route.
2. Select an owned Android phone that reports current sender readiness.
3. Choose **Synced contacts from phone** or **CSV file**.
4. Enter the shared message.
5. Review accepted destinations, exclusions, duplicates, and segment estimates.
6. Create the draft.

Creation snapshots the message and recipients. It does not start dispatch. The contact source and sending device are the same phone for this milestone. The CSV path also requires a selected sending phone.

The job is limited to 5,000 unique eligible ordinary Pakistani mobile destinations. Oversized, malformed, foreign, landline, service, short, premium, and unrecognized inputs are blocked.
