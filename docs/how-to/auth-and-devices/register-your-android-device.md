# Register an Android phone

1. Install and open the verified Android APK.
2. Sign in with the same owner account used in the web admin.
3. Complete device registration and give the phone a recognizable name.
4. Configure a default SMS subscription in Android.
5. Grant SMS permission and explicitly enable the sender in SMSApp settings.
6. Keep the app open until the web admin shows the device.

New registrations are not enrolled to send by default. The admin should treat the phone as unavailable until it reports current SMS permission, a default SMS subscription, an active sender service, and the supported queue protocol.

Registration does not share the phone with other accounts. The first release supports owner-managed phones only and one selected phone per job.
